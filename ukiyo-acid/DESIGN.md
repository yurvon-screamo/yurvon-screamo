# UKIYO-ACID — дизайн-система и мудборд

> Спецификация веб-стиля: японская психоделия 60-х + acid graphics, тёмный editorial-лонгрид.
> Назначение: руководство для дизайнера и разработчика. Документ — источник истины по визуальному языку проекта.
> v3 (после юзер-ревью демо): истинный чёрный `#000`, насыщенные неоны, зерно 14–18%, коллажные неоновые поля.

---

## 0. Design Read

**Читаем задачу как:** editorial-лонгрид (культурологический/музейный формат) для дизайн-аудитории, с языком «плакат вместо страницы»: тёмная база, коллажные сцены, кислотные акценты. Ориентир — учебный проект про Таданори Ёкоо (artsasha_tilda) и традиции японского психоделического плаката.

**Dials:**

| Dial | Значение | Обоснование |
|---|---|---|
| DESIGN_VARIANCE | 9/10 | Слом сетки — часть языка: наложения, коллажи, вертикальный текст |
| MOTION_INTENSITY | 6/10 | Скролл-ревилы и параллакс дозированно; драматургия без каруселей |
| VISUAL_DENSITY | 3/10 | Воздух: коллажные «взрывы» чередуются с тихими текстовыми секциями |

**Одной фразой стиль:** укиё-э, вырванные из альбомов и вклеенные в чёрный кислотный плакат 1968 года, сверстанные в 2026-м.

## 2. Дизайн-спека

### 2.1 UX-стратегия

Формат — иммерсивный лонгрид с двумя режимами потребления:

1. **Погружение** — скролл-путешествие по коллажным сценам, минимум текста, максимум атмосферы.
2. **Чтение** — спокойные текстовые секции между «взрывами»: основной текст, архив, глоссарий.

Логика повествования: каждая глава раскрывает один символ (солнце, волна, милитаризм, кайдзю). Цветовая нить (красный) проходит сквозь все главы и связывает их. Переходы между главами — полноэкранные коллажные сцены-разделители.

Дополнительные механики:

- Переключатель режимов «Вселенная / Лонгрид» (как в референсе с поста) — вне scope v1: добавляется в v2, если лонгрид наберёт больше 4 глав; в чек-лист приёмки v1 не входит.
- Глоссарий символов с mono-подписями и ruby-аннотациями чтения кандзи — в scope v1.

### 2.2 Цвет

Палитра строится по правилу **70 / 20 / 10**: 70% истинного чёрного, 20% бумаги и монохромной графики, 10% кислотных полей. В коллажных сценах неоны могут заливать поля целиком (плакатный приём), в тихих секциях держатся 70/20/10.

| Токен | HEX | Роль | Контраст на `--bg` |
|---|---|---|---|
| `--bg` | `#000000` | Истинный чёрный, фон страницы | — |
| `--surface` | `#0E0E10` | Карточки, оверлеи | — |
| `--ink` | `#1A1A1E` | Глубокие тени коллажей, рамки | — |
| `--line` | `#26262B` | Разделители, hairlines | — |
| `--paper` | `#F2E9D8` | Основной текст, «васи»-вставки | ≈17:1 |
| `--sun` | `#FF2A1F` | Красная нить: солнце, занавес, флаги | ≈5.6:1 |
| `--sun-bright` | `#FF5540` | Красный для мелкого текста | ≈6.6:1 |
| `--acid` | `#AAFF00` | Кислотный акцент: хайлайты, поля коллажей | ≈17:1 |
| `--neon` | `#FF1F8F` | Электрик-розовый: поля коллажей, штампы | ≈5.9:1 |
| `--gold` | `#FFB000` | Дейгло-янтарь: метки, глоссарий | ≈11.5:1 |

Правила:

- Красный `--sun` — сюжетный цвет, не декор. Он появляется в каждой главе и «ведёт» читателя.
- На всей странице активны **максимум два неона одновременно**: `--acid` + `--neon`. `--gold` — нейтральный исторический акцент.
- `--sun` на истинном чёрном даёт ≈5.6:1 и проходит AA для обычного текста; для мелкого текста предпочтителен `--sun-bright`.
- Пары с красным фоном: `--bg` на `--sun` ≈5.6:1 — AA для обычного текста, разрешена; `--paper` на `--sun` ≈3.1:1 — только large-text (≥24px или ≥18.66px bold). Мелкий текст на красном фоне — только `--bg`.
- Светлые вставки (`--paper`-фона) допустимы как «страницы альбома»: на них текст — `--ink`.

### 2.3 Типографика

Все шрифты бесплатны, с поддержкой кириллицы, самохостинг (`@font-face` + `font-display: swap`).

| Роль | Шрифт | Вес | Подмножества | Применение |
|---|---|---|---|---|
| Display | **Unbounded** | 700–900 | latin, cyrillic | H1–H2, плакатные титулы, растянутые капсы |
| Плакатный акцент | **Rubik Mono One** | 400 | latin, cyrillic | Тех-метки, штампы, номера глав (редко) |
| Body | **Golos Text** | 400–600 | latin, cyrillic | Основной текст, lead |
| Mono | **IBM Plex Mono** | 400–500 | latin, cyrillic | Подписи, глоссарий, даты, «архивные» данные |
| Japanese | **Noto Serif JP** | 500–700 | japanese, latin | Вертикальные вставки, ruby-аннотации |

Fallback-стеки (подключать подгружаемые подмножества отдельно; `size-adjust` — по замеру метрик):

```css
--font-display: "Unbounded", "Golos Text", system-ui, sans-serif;
--font-body: "Golos Text", system-ui, -apple-system, "Segoe UI", sans-serif;
--font-mono: "IBM Plex Mono", ui-monospace, "Courier New", monospace;
--font-ja: "Noto Serif JP", "Hiragino Mincho ProN", "Yu Mincho", serif;
```

Type scale (fluid, через `clamp()`):

| Роль | Размер | Межстрочный |
|---|---|---|
| H1 | `clamp(2.75rem, 6vw, 5.5rem)` | 1.05 |
| H2 | `clamp(2rem, 4vw, 3.5rem)` | 1.1 |
| H3 | `clamp(1.5rem, 2.5vw, 2.25rem)` | 1.2 |
| Lead | `clamp(1.125rem, 1.5vw, 1.375rem)` | 1.5 |
| Body | `clamp(1rem, 1.2vw, 1.125rem)` | 1.6 |
| Mono-подпись | `0.8125rem`, капс, трекинг +6% | 1.4 |
| Метка (Rubik Mono One) | `0.75rem` | 1.3 |

Японская типографика (обязательные правила):

- Каждый японский фрагмент — в разметке с `lang="ja"` (скринридеры читают кандзи китайскими чтениями без него).
- Ruby: база — `--font-ja`, `rt` — 50% от размера базы, цвет `--gold`, `ruby-align: center`.
- Переносы CJK: `line-break: strict; word-break: normal;` на японских блоках.
- Вертикальные вставки: фиксированная высота блока по контенту; при переполнении — перенос во вторую колонку (`column`), не обрезка.

Маппинг ролей на заголовки: H1–H2 — Unbounded (веса из таблицы); H3 — Golos Text 600 (подразделы внутри глав); body — Golos Text 400; подписи и глоссарий — IBM Plex Mono; метки и штампы — Rubik Mono One; японские вставки и ruby — Noto Serif JP.

Приёмы:

- Вертикальный текст (`writing-mode: vertical-rl`) для японских титулов на краях секций; на мобильных — горизонталь.
- Ruby-разметка (`<ruby>`) для чтения кандзи в глоссарии.
- Display-заголовки: трекинг от -1% до +8% (капсы с разрядкой — как на плакатах Ёкоо).
- Иерархия глав: mono-метка (глава/номер) → display-титул → lead Golos Text.
- Микрографический слой (тренд-приём): каталожные номера пластин, координаты, даты и служебные подписи mono поверх и вокруг коллажей. Правила: mono-метки всегда осмысленны или явно демо-помечены, не заменяют содержательные подписи и не лежат на смысловых текстовых блоках.

### 2.4 Композиция и сетка

База: 12 колонок, контейнер 1200–1440px, поля 24/32px. Коллажные сцены сознательно ломают сетку.

- **Ритм глав:** тихая текстовая секция → нарастание (архив, карточки) → коллажный «взрыв» на всю ширину. Минимум 4 из 5 layout-семейств на лонгрид.
- **Layout-семейства (полный список):** (1) full-bleed коллажная сцена; (2) тихая текстовая секция; (3) архивная сетка карточек; (4) цитата-плакат на всю ширину; (5) mono-таблица/глоссарий.
- **Наложения:** до 3 слоёв графики на сцену (гравюра + фото + неон-плашка), смещения по сетке на 1–3 колонки, повороты ≤3°.
- **Full-bleed:** сцены-разделители глав — на всю ширину вьюпорта.
- **Вертикальные рельсы:** японские титулы вдоль краёв секций создают рамку композиции.
- **Тишина:** текстовые секции без графики вообще — только `--paper` на `--bg`. Контраст темпа и есть драматургия.
- Коллажи никогда не переносят смысловой текст поверх себя; подписи живут в mono-плашках рядом.

### 2.5 Изображения и обработка

Источники: public domain архивы (Met, LoC — см. мудборд, слой 2) + собственная графика «в духе».

Обработка (единый конвейер, чтобы коллажи смотрелись серией):

1. Duotone: ч/б гравюры тонировать парой `--ink`/`--paper` или `--ink`/`--sun`.
2. Зерно двухслойное (SVG `feTurbulence`: обесцвеченный контрастный шум, тип `turbulence`): `screen`-слой ~16% — светлая крапинка на тёмном; `multiply`-слой ~14% — тёмная крапинка на светлом и насыщенных полях. Тайлы разного масштаба (240/260px) декоррелируют слои, иначе крапинка взаимно гасится. Причина двух слоёв: на истинном чёрном невидим полупрозрачный слой в нормальном режиме, а на ярко-насыщенном поле невидим одиночный screen (каналы уже на максимуме).
3. Вырезанный край: маски «рваной бумаги» для вклеек (SVG-маски, не PNG-мусор).
4. Смешение: `mix-blend-mode: screen` для неона на чёрном, `multiply` для гравюр на бумаге.
5. Неон-плашки: чистые геометрические формы (лучи, искры) поверх фотомонтажа.

Форматы: WebP/AVIF, `srcset`, `loading="lazy"` для всего ниже фолда; hero-изображение — приоритетная загрузка (LCP).

### 2.6 Моушн

| Элемент | Поведение | Тайминг |
|---|---|---|
| Появление секций | fade + сдвиг 24px, каскад 80мс между элементами | 300ms, `cubic-bezier(0.16, 1, 0.3, 1)` |
| Коллажные сцены | параллакс слоёв (2 скорости) | GSAP ScrollTrigger |
| Неон-плашки | появление «вспышкой» (opacity 0→1, scale 0.94→1) | 200ms |
| Ховер карточек архива | инверсия: карточка заливается `--acid`, текст — `--bg` | 150ms |
| Красная нить | линия/луч «дорисовывается» при переходе главы | GSAP ScrollTrigger |

Запреты: `window.addEventListener('scroll')` — только IntersectionObserver или GSAP ScrollTrigger; бесконечные циклические анимации; моушн ради моушна.

Единая система моушна (решение, без развилок): **GSAP ScrollTrigger** — предсказуемая кроссбраузерность, обязательный cleanup `ctx.revert()` при размонтировании. CSS scroll-driven animations в v1 не используются. `prefers-reduced-motion: reduce`: параллакс и каскады отключаются, остаётся статичный рендер с fade 150ms.

### 2.7 Интерактивные состояния

- Ссылки в тексте: подчёркивание `--acid`, ховер — инверсия плашки.
- Кнопки: плоские плашки без радиуса (0–2px), ховер — заливка `--acid`, текст `--bg`.
- Карточки архива: ховер-инверсия + mono-подпись выезжает снизу.
- Фокус: видимый focus-ring 2px `--acid` со смещением 2px — на всём интерактивном.
- Отключение async-кнопок на время запроса.

### 2.8 Доступность

- Контраст: все пары текст/фон из таблицы 2.2 проверены; красный мелкий текст — только `--sun-bright`.
- Alt-тексты для всех коллажей, описывающие содержание сцены, а не «картинка».
- Цвет не единственный носитель смысла: активные элементы имеют и форму/подпись.
- Клавиатурная навигация и порядок фокуса соответствуют визуальному порядку, включая галерею гравюр (см. 2.10.5).
- Японские фрагменты размечены `lang="ja"` (корректное чтение кандзи скринридерами).
- `prefers-reduced-motion` — см. 2.6.

### 2.9 Адаптив

Точки: 1440 / 1024 / 768 / 375.

- <768px: коллажные сцены складываются в один столбец, максимум 2 слоя графики; вертикальные японские титулы — в горизонталь; сетка архива — 1 колонка с сохранением пропорций карточек.
- Параллакс отключается на touch-устройствах (медиа `(hover: none)`).
- Никакого горизонтального скролла **страницы** на любых ширинах. Высоту полноширинных сцен задавать по контенту (`min-height` по содержимому), а не фиксированными `100vh`/`100dvh`; только hero может использовать `min-height: 100dvh`. Исключение — галерея гравюр (2.10.5): горизонтальный скролл внутри её контейнера разрешён и не должен протекать за его пределы (overflow-x скрыт на уровне страницы, скролл ловится контейнером).

### 2.10 Структура страницы-примера

1. **Hero** — full-bleed коллажная сцена, вертикальный японский титул, display-заголовок ≤2 строк, одна кнопка.
2. **Пролог** — тихая секция: lead на `--paper`, 60–80 слов.
3. **Глава 1: Солнце** — архив (сетка карточек 2–3 колонки) → коллажный взрыв (лучи, `--sun`).
4. **Интерлюдия** — цитата-плакат на всю ширину: красный фон `--sun`, основной текст `--bg` (≈4.7:1, AA); display-цитата ≥24px может быть `--paper` (large-text критерий); метка Rubik Mono One — на плашке `--paper` с текстом `--ink`.
5. **Глава 2: Волна/гравюры** — горизонтальная галерея гравюр: scroll-snap + стрелки-кнопки, фокус с клавиатуры, свайп на touch; каждая карточка — `figure` с mono-подписью, контейнер — `role="region"` + `aria-label`.
6. **Глава 3: Милитаризм** — фотомонтажная сцена: ч/б архив + неон-плашки, максимально «документальный» тон.
7. **Глоссарий** — mono-таблица символов с ruby-аннотациями.
8. **Колофон** — источники, шрифты, благодарности (обязателен: часть этики стиля — видимость архивов).

## 3. Анти-паттерны (что запрещено)

Стилевые:

- Случайные кандзи «для атмосферы» — любая японская графика осмысленна и переведена.
- Больше двух неонов одновременно; сакура/веер/манга-клише; «wabi-sabi минимализм» вперемешку с кислотой.
- Градиентные фиолетово-синие свечения (AI-tell), стекломорфизм, скруглённые карточки с тенями.

## 4. Заметки для реализации

- **Стек:** Astro или статика + Tailwind (утилиты для токенов через CSS-переменные); моушн — только GSAP ScrollTrigger (обязателен `ctx.revert()` в cleanup), как решено в 2.6.
- **Перфоманс:** бюджет LCP < 2.5s, замер Lighthouse/PageSpeed на mid-tier мобильном эмулировании; коллажи собирать в композитные изображения, где возможно, а не 10 absolute-слоёв; зерно — CSS/SVG, не фоновая PNG-текстура на всю страницу.
- **Токены:** все значения из 2.2–2.3 заводить как CSS custom properties, без хардкода цветов в разметке.
- **Право:** укиё-э — public domain (проверять конкретный скан и условия архива); работы Ёкоо/Танаами/Кимуры — под копирайтом: в проде использовать только собственную графику «в духе», образы Годзиллы — IP Toho, нельзя.
