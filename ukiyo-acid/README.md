# UKIYO-ACID

Design system and self-contained demo page for a future portfolio site.

Style: 1960s Japanese psychedelic poster (Tadanori Yokoo, Keiichi Tanaami) fused with acid graphics, on true black. Dark editorial longread format.

## Files

- `DESIGN.md` — moodboard + full design spec (palette, typography, layout, motion, a11y, acceptance checklist). Source of truth, v3.
- `index.html` — working demo, fully self-contained (inline SVG art, no build step, no external images). Open it in a browser.

## Status

Demo approved visually. Known production gaps are flagged in the HTML head comment: self-hosted fonts instead of CDN, npm GSAP instead of CDN, real public-domain ukiyo-e scans instead of SVG stylization.
